## 📌 Project Title
Hostel Management System

---

## 🧠 Problem Statement
Managing hostel operations manually is inefficient and error-prone. Tasks like student allocation, room management, fee tracking, and complaint handling require a structured system. This project aims to digitize these operations using a Java-based desktop application.

---

## 🚀 Key Features
- Warden Login System
- Student Management (Add/View)
- Room Allocation & Transfer
- Complaint Management System
- Fee Tracking System
- Dashboard Overview

---

## 🛠️ Technology Used
- Java (Core + OOP)
- Java Swing (GUI)
- (Planned) MySQL + JDBC for database

---

## 🗄️ Database Setup
Currently, the project uses in-memory storage.

Future scope:
- MySQL database using JDBC
- Tables: Students, Rooms, Complaints, Fees
