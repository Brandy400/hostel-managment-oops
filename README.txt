# Hostel Management System

## Developed by
Saransh Upadhyay

## Description
A Java-based Hostel Management System using OOP and Swing GUI.

## Features
- Student Management
- Room Allocation
- Complaint System
- Fee Management
- Warden Login

## Tech Stack
- Java (Core + OOP)
- Java Swing

## How to Run
javac -d bin $(find src -name "*.java")
java -cp bin com.hostel.app.HostelManagementSystemGUI
